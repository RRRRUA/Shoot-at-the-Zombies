# 向僵尸开炮游戏机器人

一个用于自动化游戏操作的Python脚本，支持自动刷环球、刷卡关等功能。

## 功能特性

### 核心功能
- 🎯 **自动刷环球** - 自动加入队伍并战斗
- 🎮 **自动主线** - 自动挑战主线关卡
- ⚔️ **普通远征** - 自动刷普通远征模式
- 🔥 **超级远征** - 自动刷超级远征模式
- ⚡ **技能优先级** - 支持设置5个优先技能，按顺序匹配
- 💰 **消费模式** - 支持选择「我是土豪」或「我是穷B」模式，影响远征策略
- 🏃 **秒退模式** - 支持开启秒退功能（普通远征、超级远征、主线模式可用）
- 📊 **战斗次数统计** - 实时显示当前战斗次数，点击开始时自动清零
- 🔍 **图像识别** - 使用OpenCV进行模板匹配
- 🪟 **窗口内容识别** - 可通过游戏窗口中的固定区域查找窗口，不依赖窗口标题
- 🖥️ **图形界面** - 友好的Tkinter GUI操作界面
- 💾 **配置保存** - 自动保存技能配置，下次启动自动加载
- ⌨️ **快捷键** - 按ESC键暂停脚本
- 📏 **窗口大小调整** - 一键调整游戏窗口为推荐的542*1010大小

### 技术特点
- 支持Windows PC端微信小程序
- 支持多模板匹配（每个技能可设置多个模板）
- 支持PyInstaller打包为可执行文件
- 支持按窗口标题或窗口内容查找游戏窗口
- 窗口内容模板支持多尺度匹配和多模板任选其一匹配
- 异常处理和错误提示
- 实时状态显示

## 快速开始

### 环境要求
- Windows操作系统
- Python 3.13+
- [uv](https://docs.astral.sh/uv/)

### 安装依赖
项目使用`uv`管理虚拟环境和依赖。进入项目根目录后执行：

```bash
uv sync
```

`uv sync`会根据`pyproject.toml`和`uv.lock`创建或更新项目虚拟环境，并安装以下依赖：

- `numpy`
- `opencv-python`
- `pillow`
- `pyautogui`
- `pynput`
- `pywin32`

### 目录结构
```
├── game_bot.py        # 主脚本文件
├── pyproject.toml      # 项目配置和依赖声明
├── uv.lock             # uv锁定的依赖版本
├── config.json        # 配置文件（自动生成）
├── screenshots/       # 截图保存目录
└── templates/         # 模板图片目录
    ├── skill.png      # 技能模板
    ├── battle.png     # 战斗按钮模板
    ├── window-anchor.png    # 窗口内容识别模板
    ├── window-anchor-2.png  # 可选的第二张窗口内容模板
    └── ...            # 其他界面元素模板
```

### 运行方式

#### 方法1：图形界面
```bash
uv run python game_bot.py
```

#### 方法2：命令行参数
```bash
uv run python game_bot.py --game_title "向僵尸开炮" --mode 0 --battle_count 10
```

## 使用指南

### GUI界面说明
1. **游戏窗口标题** - 输入游戏窗口的标题（默认为"向僵尸开炮"）
2. **模式选择** - 选择运行模式：
   - **环球** - 自动刷环球（进别人队伍）
   - **主线** - 自动挑战主线关卡
   - **普通远征** - 自动刷普通远征
   - **超级远征** - 自动刷超级远征
3. **消费模式** - 选择消费策略（仅在环球、普通远征、超级远征模式下显示）：
   - **我是土豪** - 不检查门票，直接挑战
   - **我是穷B** - 检查门票，避免不必要的消耗
4. **秒退模式** - 勾选开启秒退（仅在普通远征、超级远征、主线模式下显示），战斗结束后立即退出
5. **战斗次数** - 设置战斗次数（0表示无限循环）
6. **战斗时间** - 设置每次战斗的最大时间（0表示无限制）
7. **优先技能** - 从下拉框选择5个优先技能（按优先级从上到下）
8. **开始/停止** - 控制脚本运行，点击开始时战斗次数自动清零
9. **调整窗口大小** - 一键将游戏窗口调整为推荐的542*1010大小，提高识别准确率

### 模板图片准备
在`templates`目录中添加以下模板图片：
- `window-anchor*.png` - 窗口内容识别模板，可以是游戏窗口中的局部固定区域
- `skill.png` - 技能按钮
- `battle.png` - 战斗按钮
- `battling.png` - 战斗中状态
- `return.png` - 返回按钮
- 其他界面元素模板

**注意**：为了提高识别准确率，建议使用游戏窗口的原始分辨率，窗口大小推荐使用542*1010。

### 窗口内容识别

程序支持使用窗口内容中的固定区域识别游戏窗口。窗口内容模板不需要覆盖整个窗口，只需要截取一块稳定、具有辨识度的区域即可，例如固定图标、文字或装饰。

将模板放入`templates`目录，并使用以下命名方式：

```text
window-anchor.png
window-anchor-2.png
window-anchor-3.png
```

程序会自动读取所有`window-anchor*.png`文件，并在候选窗口中进行匹配。只要任意一张模板的匹配度达到阈值，就会认定该窗口为游戏窗口。程序同时支持约50%到200%的窗口缩放。

窗口内容识别模板应满足以下条件：

- 内容在游戏过程中基本不变；
- 不要包含倒计时、血量、动画或其他动态区域；
- 尽量包含清晰的图标、文字或独特图案；
- 可以从同一个游戏窗口截取多个不同区域，提高识别成功率。

窗口内容识别配置位于`game_bot.py`顶部：

```python
WINDOW_CONTENT_TEMPLATE = "window-anchor.png"
WINDOW_CONTENT_THRESHOLD = 0.82
```

如果没有可用的窗口内容模板，程序会退回按窗口标题查找。窗口内容匹配失败时，也会尝试使用界面中填写的窗口标题。

## 注意事项

1. **兼容性** - 使用OpenCV图像对比，可能对不同分辨率和设备有兼容性问题
2. **干扰** - 游戏过程中尽量不要操作鼠标和键盘，以免干扰脚本运行
3. **权限** - 确保脚本有足够的权限控制鼠标和键盘
4. **安全** - 本脚本仅供学习参考，请勿用于商业用途或破坏游戏平衡
5. **更新** - 游戏更新后可能需要更新模板图片

## 常见问题

### Q: 脚本找不到游戏窗口
A: 首先检查`templates/window-anchor*.png`是否来自当前游戏界面，且固定区域没有发生变化。如果使用标题查找，请确保游戏窗口标题填写正确。窗口内容匹配日志中的匹配度需要达到`WINDOW_CONTENT_THRESHOLD`，默认值为`0.82`。

### Q: 窗口内容匹配度较低
A: 重新截取当前游戏窗口中的固定图标、文字或装饰区域，避免使用动态内容。也可以添加多张`window-anchor*.png`模板；程序只需要其中一张匹配成功即可。

### Q: 技能识别失败
A: 检查`templates`目录中的技能模板图片是否正确

### Q: 脚本运行不稳定
A: 调整游戏窗口分辨率为推荐的542*1010，确保模板图片清晰
